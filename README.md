# Recherche Mathis

Veille d'offres d'emploi, d'événements et de programmes en paix, médiation et éducation non formelle.

- Le site : `index.html` (une seule page, sans dépendance).
- Les données : `data/jobs.json`, `data/events.json`, `data/programs.json`, `data/meta.json`.
- Mise à jour : des tâches planifiées Claude ajoutent les nouvelles entrées chaque matin (offres) et chaque lundi (événements, programmes). Elles n'effacent ni ne modifient jamais une entrée existante.
